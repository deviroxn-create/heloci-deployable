THE SOLUTION
================================================================================

1. Import C.1 AudienceResolver (from lib/communications/runtime)
2. Build proper CommunicationRequest with stage marker
3. Call C.1 resolver instead of legacy
4. Receive AudienceResolvedRequest

6. Continue with existing pipeline

Result: Full integration achieved in 2 hours with ZERO breaking changes.
